# 信息浮窗页眉排版调整设计

## 背景

当前页眉使用左右两列 Flex 布局：标题和说明文字共用左列，操作按钮占右列。说明文字设置了 `max-width: 260px`，右侧按钮又会继续压缩左列，导致说明文字集中在狭窄区域；“设置”按钮缺少禁止换行规则，在空间不足时会拆成上下两行。

## 目标

- “打开浮窗”和“设置”按钮统一高度、横向显示且不换行。
- 两个按钮并排靠页眉右上角，并向上、向右收紧。
- 按钮底部不低于“网申信息浮窗”标题的底线。
- 说明文字独占下一行，向右铺满页眉剩余宽度，不受按钮区域挤压。
- 在窄窗口中优先压缩按钮间距和横向内边距，不将“设置”拆行。

## 布局设计

将页眉改为两行结构：

1. `panel-header-main` 作为第一行，左侧放标题，右侧放 `header-actions`。
2. `panel-subtitle` 作为页眉第二行，脱离标题容器并占据完整宽度。

`panel-header` 改为纵向布局；第一行使用 Flex 横向排列并顶端对齐。操作按钮设置一致的固定最小高度和 `white-space: nowrap`，同时取消由内容差异造成的高度变化。

移除说明文字的 `max-width: 260px`，改为 `width: 100%`，使其按整个页眉宽度自然换行。

在不超过 360px 的窗口中仍保留两行页眉结构，只缩小操作按钮的间距与横向内边距，不再把整个标题行改成纵向排列。

## 范围

修改：

- `src/sidepanel/App.tsx`：调整页眉 DOM 分组。
- `src/sidepanel/index.css`：调整页眉、按钮和窄屏规则。
- 对应测试：验证标题行结构、按钮不换行和说明文字全宽规则。

不修改按钮行为、标题和说明文案，也不修改信息字段区域。

## 验收标准

1. “设置”始终保持横向一行。
2. 两个按钮高度一致，并位于标题右侧且靠近右上角。
3. 两个按钮的底部不超过标题底线。
4. 说明文字在按钮下方独占整行，能使用页眉完整宽度。
5. 侧边栏模式和浮窗模式中的对应按钮均保持一致布局。
6. 现有按钮点击行为和信息字段功能不受影响。
