# 信息窗口专业技能卡片样式调整设计

## 背景

信息窗口中的“专业技能”目前使用独立的 `field-row single-field-record` 样式，并显示“技能 1”“技能 2”等序号标签。该表现与教育经历、项目经历、奖项 / 荣誉等栏目使用的卡片体系不一致。

## 目标

- 专业技能沿用信息窗口其他经历栏目相同的卡片视觉结构。
- 每条技能独立展示为一张卡片。
- 卡片只展示技能内容，不展示序号或“技能”标签。
- 保留点击技能后写入当前网页输入框的交互。
- 保留专业技能分区标题、数量统计、折叠能力和空数据隐藏逻辑。

## 实现设计

在 `SkillsSection` 中，将每条技能渲染为 `record-card`，卡片内部使用现有 `field-list` 和 `field-button` 结构承载技能文本。技能文本作为卡片唯一内容，不渲染 `技能 ${index + 1}`。

继续使用原始数组下标生成稳定工作键 `skill-${index}`，因此过滤空技能后不会改变既有点击行为和写入状态识别。

不修改 `UserProfile.skills` 数据结构，不修改设置页专业技能编辑器，也不引入新的通用组件或样式。

## 测试与验收

更新 `ProfileSections` 测试，验证：

1. 每个有效技能均使用 `record-card` 结构展示。
2. 页面不出现“技能 1”“技能 2”等序号标签。
3. 空技能仍被过滤。
4. 点击技能仍传递正确的技能值和工作键。
5. 专业技能仍位于项目经历之后、奖项 / 荣誉之前。
